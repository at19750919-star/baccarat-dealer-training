💡 先搞懂「狀態」這個詞：寫提示詞最常漏的就是狀態。 hover（懸停）＝滑鼠移上去（手機沒有）； press / active（按下）＝手指或滑鼠按住（手機端主要靠這個）； focus（聚焦）＝點進輸入框； disabled（禁用）＝條件不足時灰掉。 一個按鈕至少要交代 預設 / hover / 按下 / 禁用 / loading 五態，AI 才知道怎麼做。

主要按鈕 Primary Button
頁面上最重要、希望使用者點的那個動作，整頁通常只有一個。
何時用：提交、確認、下一步。記得交代 hover／按下／禁用三態。
次要按鈕 Secondary / Ghost
次要動作，用描邊或淺色，視覺上「讓位」給主要按鈕。
何時用：取消、返回、輔助操作，跟主要按鈕並排出現。
圖示按鈕 Icon Button
只有一個圖示、沒有文字的按鈕，省空間。
何時用：工具列、卡片角落。一定要配 tooltip 說明，不然看不懂。
懸浮操作按鈕 FAB
浮在右下角的圓形主按鈕，捲動時固定不動。
何時用：該頁最核心的單一動作，如「新增」「發文」。

跳轉到另一個位置或頁面，帶底線、藍色。
何時用：「導航」用連結，「執行動作」用按鈕，別混。

讓使用者打字輸入，聚焦(focus)時邊框高亮。
何時用：表單。記得交代 placeholder、focus 與錯誤狀態。

單選按鈕 Radio
一組裡「只能選一個」，互斥。
何時用：性別、付款方式等只能擇一的選項（≤5 項）。
開關 Switch / Toggle
即時生效的「開/關」，不需要再按儲存。（試點我）
何時用：設定頁的單一功能，如「深色模式」「通知」。

工具提示 Tooltip
hover 才出現的純文字小提示，不能放按鈕。
何時用：解釋一個圖示是什麼意思。手機沒 hover，慎用。

輕提示 Toast / Snackbar
一閃而過的通知，幾秒後自動消失，不打斷操作。
何時用：「已儲存」「網路錯誤」等輕量回饋。

右鍵選單 Context Menu
在某元素上長按／右鍵叫出的動作清單。
何時用：列表項、檔案的「更多操作」。
進度條 Progress Bar
顯示明確進度（百分比），讓使用者知道還要多久。
何時用：上傳、下載、多步驟完成度。
載入轉圈 Spinner
不知道要多久時的「等待中」動畫。
何時用：按鈕提交後、短時間請求。太久建議改骨架屏。
骨架屏 Skeleton
內容載入前的灰色占位 + 微光掃動，比轉圈高級。
何時用：列表、卡片、個人頁等版型固定的內容載入。

何時用：訂單狀態、標籤分類、未讀數量。

標籤頁 Tabs
在同一頁切換不同分類內容，當前頁有底線高亮。
何時用：同一畫面下的 2～5 個平行分類。

分頁 Pagination
把長清單切成多頁，逐頁翻看。
何時用：資料量大、需要明確頁碼時（替代無限捲動）。
