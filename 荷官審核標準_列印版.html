百家樂荷官審核標準

適用對象:新進荷官資格認證
制度說明:學科與術科雙軌分開考核,兩科皆通過方可正式上桌。

考核架構

科別形式考核方式通過門檻
學科理論/知識/判斷電腦選擇題80% 以上
術科實地操作/手法/臨場主管現場評分7 大項每項達 B 級以上
通過流程:學科合格 → 可進入術科實作評核 → 術科合格 → 正式上桌。

一、學科(理論知識)

A. 題庫組成

共 18 題,涵蓋三大類:

題型題數內容
情境判斷題7 題活碼/泥碼混淆、切牌異議、代下注、截止後加注、衝突優先級、天牌判斷、公共安全事件
計算題6 題抽水計算(乘五去尾)、多注結算、泥碼/活碼轉換、幸運六、莊勝 6 點特殊賠、桌面差額
違規辨識題5 題結算順序、露牌處置、籌碼私藏、碰觸客人牌、手機攜入

B. 學科通過標準

得分判定評語
100%完美滿分理論知識紮實,可以正式上桌
≥ 80%通過小部分需複習
< 80%未達標請重新研讀教材再測驗

C. 學科涵蓋範圍

學科分類涵蓋主題
牌例(規則、機率)基礎規則與機率背景、第三張牌補牌矩陣
賠付(公式、抽水)賠率與結算、抽水心算、速算技巧
SOP(流程判斷)發牌流程標準 SOP、切牌削牌開新靴
臨場判斷異常狀況處理、客戶服務話術
活碼/洗碼活碼制度與洗碼量

二、術科(實地操作)

評分等級定義(通用)

等級描述
A(優秀)動作流暢、零失誤、節奏穩定、口令清晰,可作示範
B(合格)動作正確、偶有小瑕疵但不影響流程,主管無需介入
C(待加強)動作勉強完成,出現需提醒/糾正的錯誤,流程中斷
未達標出現紅線違規,或關鍵步驟錯誤造成無法繼續
術科通過條件:7 大項每項至少 B 級以上;任一項 C 級 → 需補考該項;任一項出現紅線 → 整體不通過。

1. 洗牌(Shuffle)

考核目的:確認能獨立完成完整洗牌流程,動作安全、無露牌。

觀察指標:

  • 展示牌組:8 副牌面朝上完整展示給客人確認
  • Wash 洗牌:手法流暢、無飛牌/翻面/露點
  • 切牌板交予客人切牌
  • 銷牌依第一張點數正確銷入(A=1、2-9=面值、10/JQK=10)
  • Cut Card 插入距底部 14~16 張 處
  • 裝入牌靴面朝下
紅線(出現即未達標)
  • 洗牌過程中有任何一張牌露點
  • 銷牌張數錯誤且未自我察覺
  • 私藏/掉牌未通報

2. 牌例(規則應用)

考核目的:實際牌局中能正確應用補牌與天牌規則,不需他人提示。

觀察指標:

  • 閒家補牌規則應用正確(點數 0-5 補、6-7 停)
  • 莊家補牌矩陣應用正確(依莊家點數 × 閒家第三張比對)
  • 天牌(Natural 8/9)優先判斷正確,立即停止補牌
  • 翻牌後報點清晰,不含混
  • 連續 5 局實測無補牌決策錯誤
紅線
  • 天牌未辨識仍繼續補牌
  • 莊補牌矩陣判斷錯誤且未自我察覺

3. 賠付(結算)

考核目的:結算順序正確、速算準確、籌碼動作規範。

觀察指標:

  • 結算順序:先收輸家 → 再賠贏家 → 結算和局 → 結算邊注
  • 方向:由右至左(荷官視角)
  • 抽水計算:莊勝時 5% 抽水心算準確(乘五去尾法)
  • 幸運六/對子等邊注賠率正確
  • 籌碼推放:整齊、落在對應格內、不散放
  • 標記水錢後再移至下個座位
紅線
  • 先賠贏家、後收輸家
  • 跳過座位,不按右至左順序
  • 先結算邊注再結算主注
  • 使用「贏」「輸」等情緒性詞彙宣告結果
  • 標記水錢前已移動到下個座位
  • 抽水計算錯誤且未自我察覺

4. 桌上禮儀(儀態、手勢、服務)

考核目的:符合職業荷官儀態標準,手勢規範,與客人互動得體。

觀察指標(手勢):

  • 開放下注:掌心向上、手臂微展
  • 停止下注:手掌朝下、由內向外水平揮動
  • 發牌:拇指+食指夾牌、面朝下推出
  • 翻牌:食指押牌角、拇指翻起
  • 清手示意:雙手翻轉正反面展示給監視鏡頭
  • 呼叫主管:單手高舉、五指張開

5. 牌靴的調整(切牌、削牌、開新靴)

考核目的:開新靴流程完整無疏漏,Cut Card 位置正確,異常狀況能呼叫主管。

觀察指標:

  • 舊靴結束:露出 Cut Card 後,完成當局再停止
  • 牌靴清空、歸位、回收舊牌
  • 新靴:展示 → Wash → 客人切牌 → 銷牌 → 插 Cut Card → 裝靴
  • Cut Card 位置:距底部 14~16 張
  • 切牌過程若客人提出異議,不自行重切,舉手呼叫主管
紅線
  • 客人要求重切即配合(擅自讓客人干預牌序)
  • Cut Card 位置偏差過大(影響發牌量)
  • 銷牌流程遺漏

6. 拉牌(發牌動作)

考核目的:從牌靴抽牌動作標準、無露牌、報點清晰。

觀察指標:

  • 發牌順序:閒1 → 莊1 → 閒2 → 莊2,每張面朝下
  • 拉牌手法:拇指+食指夾牌,流暢推出,無飛牌
  • 翻牌:食指押牌角、拇指翻起,動作清晰,先閒後莊
  • 報點:清晰、準確、正確次序
  • 補第三張時機正確(天牌優先、補牌矩陣)
  • 發牌過程無露牌(Flash Card)
紅線
  • 發生露牌時自行決定處置(必須呼叫主管,由主管裁定)
  • 發牌順序錯誤
  • 已「停止下注」後又配合客人加注

7. 臨場反應(異常處置)

考核目的:面對異常狀況時,能冷靜、依 SOP、優先級正確處理。

觀察指標(以情境演練實測):

  • 優先級鐵律:監控對講機 > 主管 > 客人
  • 活碼/泥碼混淆 → 凍結桌面、呼叫主管
  • 切牌後客人異議 → 不重切,依程序繼續,主管處理
  • 客人要求代下注/記注 → 婉拒並通報
  • 截止後客人強行加注 → 維持發牌、口頭說明封盤
  • 公共安全事件(衝突、物品損毀)→ 凍結桌面、雙手離桌、等待主管與保安
  • 露牌 → 停止、舉手、由主管裁定
紅線(任一即整項未達標)
  • 自行與客人協商爭議
  • 介入公共安全事件(勸架、言語互動)
  • 私下處理金錢/籌碼往來
  • 配合客人要求違反 SOP(重切、代下注、碰客人牌)

三、總評與通過規則

科別最低通過條件補考規則
學科18 題 ≥ 80%(15 題以上正確)未達標 → 複習後重測,題目可重新抽取
術科7 大項每項 ≥ B 級,且無紅線違規單項 C 級 → 該項補考;出現紅線 → 整體重考
最終通過:學科 ✅ + 術科 7 大項全部 ✅ → 准予正式上桌
